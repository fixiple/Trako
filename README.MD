# 🚀 Trako

Trako is a full-stack application designed to centralize and streamline job and internship application tracking alongside associated task management.

# 🛠️ Tech Stack

Backend: Java, Spring Boot, Spring Data JPA, REST API

Database: PostgreSQL

Tools & Versioning: Git, Maven, Postman

# 🎯 Features & Progress

The project is currently under active development (tracked on the dev branch).

## 🛠️ Backend (REST API)

[x] Spring Boot project architecture setup

[x] PostgreSQL & JPA/Hibernate database configuration

[x] Core entity modeling (Application, Company, Task)

[x] Implementation of CRUD endpoints for application tracking

[ ] Endpoint security with Spring Security / JWT (in progress)

## 💻 Frontend (User Interface)

[ ] UI mockups and specifications

[ ] Component architecture & integration

[ ] Frontend integration with backend REST API
